Import Excel

Pilih file .xlsx atau .xls. Sistem mencocokkan CAB, NAMA GERAI, dan AKTIVITAS / PARAMETER dengan master data Supabase. Data aktivitas yang cocok akan diperbarui berdasarkan pasangan gerai + aktivitas.

Pilih file Excel dari komputer Anda.

Export Excel

Unduh seluruh data progres yang dapat diakses oleh akun Anda, termasuk nama CAB, gerai, aktivitas, tanggal rencana, tanggal aktual, progres, catatan, tindak lanjut, dan status.

Catatan: akses data tetap mengikuti Row Level Security (RLS) Supabase. File ekspor hanya berisi baris yang diizinkan untuk akun yang sedang login.
